# Captured fixtures

Real bytes, fetched from the live source and committed. Nothing in this directory is written by
hand, and nothing in this directory is regenerated by a script that talks to the network.

## Why these exist at all

The Australian feed is a **rolling 25 items with no archive**. Everything below item 25 is gone
from the source permanently — you cannot re-fetch it, and no amount of care later gets it back.
A test that reached out to `productsafety.gov.au` would therefore:

* pass or fail depending on what the ACCC published this week,
* silently stop covering the shapes it was written for, as those items roll off,
* and be unrunnable offline or in a hook.

So the harness reads these files instead. **A harness that reads a live path has an expiry date.**

## The rule

⛔ **Never hand-write or edit a fixture.** A composed record proves only that our parser satisfies
our own idea of the format. Every byte here came off the wire. If a new shape needs covering,
capture it — do not type it.

Re-capture with:

```bash
curl -sL -A "stophurting-recalls/1.0" https://www.productsafety.gov.au/rss/recalls.xml -o tools/recalls/fixtures/au-rss.xml
```

## What is here

| file | captured | source |
|---|---|---|
| `au-rss.xml` | 2026-08-16 | `https://www.productsafety.gov.au/rss/recalls.xml` — 25 items, 2026-07-09 → 2026-08-12 |
| `au-page-nevenka-baby-pull-string-giraffe-toy.html` | 2026-08-16 | the recall notice; every common field populated |
| `au-page-mondraker-onoff-s9-carbon-mtb-handlebar.html` | 2026-08-16 | the only item in the window carrying **identifying features**, and a single category |
| `au-page-pokemon-pikachu-co-bolt-teapot.html` | 2026-08-16 | a **non-ASCII slug** (`pok%C3%A9mon`) and two categories |

Three pages, chosen because they differ — one complete, one carrying an optional field the other
two lack, one whose URL is percent-encoded. A fixture set where every file is the same shape tests
one shape.

## What they are NOT

These are a parser's input, not a record of what is on the site. `state.json` is the record of
what we publish. Nothing here is ever rendered to a reader.
